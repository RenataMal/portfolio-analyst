# VK Gender Prediction

ML-проект по предсказанию пола пользователей социальных сетей на основе рекламных событий.

Проект выполнен в рамках практического проекта VK. Задача — построить модель бинарной классификации, которая определяет пол пользователя на уровне `user_id`, используя данные о рекламных событиях, географии, user-agent и URL-векторах.

## Задача

Исходные данные представлены на уровне рекламных событий:

1 строка = 1 рекламное событие

Но предсказание требуется сделать на уровне пользователя:

1 строка = 1 user_id

Поэтому ключевой частью проекта стала агрегация событий до пользовательского уровня и построение признаков для ML-модели.

## Данные

В проекте использовались несколько таблиц:

* `train.csv` — рекламные события обучающей выборки;
* `train_labels.csv` — целевая переменная;
* `test.csv` — рекламные события тестовой выборки;
* `test_users.csv` — пользователи для финального предсказания;
* `referer_vectors.csv` — числовые URL-векторы;
* `geo_info.csv` — географическая информация.

Основные группы признаков:

* активность пользователя;
* время рекламных событий;
* браузер и операционная система;
* география;
* referer/domain;
* числовые URL-векторы.

> Исходные данные не включены в репозиторий из-за возможных ограничений на распространение.

## Стек

`Python` `pandas` `numpy` `scikit-learn` `CatBoost` `LightGBM` `matplotlib` `seaborn` `Jupyter Notebook`

## Что было сделано

* проведен первичный анализ данных;
* обработаны пропуски и дубликаты;
* изучены распределения признаков и целевой переменной;
* рекламные события агрегированы до уровня пользователя;
* созданы признаки активности, географии, времени, user-agent и URL-векторов;
* обучены и сравнены модели разной сложности;
* выполнен подбор гиперпараметров CatBoost;
* сформированы предсказания для тестовой выборки.

## Feature Engineering

Для каждого пользователя были рассчитаны агрегированные признаки:

| Группа      | Примеры признаков                    |
| ----------- | ------------------------------------ |
| Активность  | количество рекламных событий         |
| URL         | количество уникальных referer/domain |
| География   | страна, регион, часовой пояс         |
| Время       | первый и последний час активности    |
| User-agent  | браузер и ОС                         |
| URL-векторы | mean, std, min, max по компонентам   |

Итоговая выборка:

```text
500 000 пользователей
55 признаков
6 категориальных признаков
49 числовых признаков
```

## Модели

В проекте были обучены и сравнены:

* DummyClassifier;
* LogisticRegression;
* RandomForestClassifier;
* LGBMClassifier;
* CatBoostClassifier;
* CatBoostClassifier с подбором гиперпараметров.

## Результаты

| Модель                 |    ROC-AUC |   Accuracy |   F1-score |
| ---------------------- | ---------: | ---------: | ---------: |
| CatBoost grid tuned    | **0.9341** | **0.8770** | **0.8702** |
| CatBoostClassifier     |     0.9276 |     0.8699 |     0.8628 |
| LGBMClassifier         |     0.9128 |     0.8512 |     0.8431 |
| LogisticRegression     |     0.8566 |     0.7929 |     0.7773 |
| RandomForestClassifier |     0.8357 |     0.7659 |     0.7423 |
| DummyClassifier        |     0.5017 |     0.5028 |     0.4788 |

Лучшая модель — **CatBoostClassifier после Grid Search**.

Финальные параметры:

```text
depth = 7
learning_rate = 0.12
l2_leaf_reg = 3
```

## Бизнес-смысл

Модель может использоваться как дополнительный сигнал для рекламной сегментации аудитории.

Потенциальная польза:

* повышение точности таргетинга;
* снижение доли нецелевых показов;
* более эффективное расходование рекламного бюджета;
* улучшение качества рекламных кампаний.

## Ограничения

* данные покрывают короткий временной период;
* у большинства пользователей только одно рекламное событие;
* классы пола закодированы как `0` и `1`;
* качество проверялось на валидационной выборке;
* реальный бизнес-эффект требует проверки через A/B-тест.
