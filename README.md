# Portfolio Analyst

Портфолио проектов в области data analytics, business analysis и system analysis.

В репозитории собраны учебные, командные и индивидуальные проекты, в которых показаны навыки анализа данных, проектирования требований, моделирования бизнес-процессов, подготовки аналитических выводов и визуализации результатов.

## Проекты

| Направление | Проект | Описание | Инструменты |
|---|---|---|---|
| Data Analytics | [E-commerce Orders Analytics](./Data%20Analytics%20Projects/e-commerce-orders-analytics) | Анализ заказов e-commerce маркетплейса: загрузка данных в PostgreSQL, проверка качества, SQL-анализ, построение витрины и дашборда. | SQL, PostgreSQL, DBeaver, DataLens |
| Data Analytics / ML | [VK Gender Prediction](./Data%20Analytics%20Projects/vk-gender-prediction) | ML-проект по предсказанию пола пользователей на основе рекламных событий, географии, user-agent и URL-векторов. | Python, pandas, scikit-learn, CatBoost, LightGBM |
| System Analysis | [AI Tender Presentation Generator](./System%20Analysis%20Projects/ai-tender-presentation-generator) | AI-сервис для автоматической генерации тендерных презентаций. Победный проект хакатона AXENIX AI Challenge. | System Design, C4 Model, Prompt Engineering, n8n |

| Business Analysis | [KTB Expert Process Optimization](./Business%20Analysis%20Projects/ktb-expert-process-optimization) | Анализ и оптимизация HR-процессов компании: AS IS / TO BE, KPI, оценка эффекта. | BPMN, SIPOC, RACI, SWOT, PESTEL, ROI |
| Business Analysis | [SF Education SWOT Analysis](./Business%20Analysis%20Projects/swot-analysis-sf-education) | Стратегический анализ EdTech-компании и разработка альтернатив развития. | SWOT, PESTEL, 5 Forces, KSF |

## Навыки

### Data Analytics

- SQL-анализ данных;
- проектирование аналитических витрин;
- проверка качества данных;
- расчет бизнес- и продуктовых метрик;
- построение дашбордов;
- формирование аналитических выводов.

### Machine Learning

- предобработка данных;
- feature engineering;
- агрегация событийных данных;
- обучение и сравнение моделей классификации;
- оценка качества моделей;
- интерпретация результатов.

### System Analysis

- сбор и формализация требований;
- описание функциональных и нефункциональных требований;
- приоритизация требований по MoSCoW;
- проектирование REST API и OpenAPI-спецификаций;
- построение ERD, BPMN и UML-диаграмм;
- описание пользовательских сценариев.

### Business Analysis

- анализ бизнес-процессов AS IS / TO BE;
- построение BPMN, SIPOC, RACI и VAD-диаграмм;
- SWOT, PESTEL и анализ пяти сил Портера;
- выявление проблем и разработка рекомендаций;
- расчет экономического эффекта;
- разработка KPI.
